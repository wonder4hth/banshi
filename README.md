# 伴时 (BanShi) — MVP

虚拟角色陪伴 + 番茄专注的网页应用，本地个人使用版。无需任何 API key。

对话有两套引擎，创建角色时可选（也可以在编辑页随时切换）：
- **本地大模型**（默认，`llm_engine.py`）：调用本机 Ollama（`http://127.0.0.1:11434`），
  真正根据你写的人设描述 + 对话上下文现场生成台词、现场构思委托，更有"活人感"。
  当前使用 `llama3.2:3b`（已在你机器上装好）。若 Ollama 没启动，会自动、无感地退回模板引擎，
  不会报错或卡住。
- **简单模板**（`dialogue.py`）：固定短句库按"说话风格 × 分心态度"组合，零延迟、完全离线。

## 运行

**先确认本地大模型服务在跑**（用于"本地大模型"引擎；不跑也没关系，会自动退回模板）：

```bash
ollama serve &          # 若已作为系统服务常驻则不需要
ollama list              # 确认 llama3.2:3b 已存在
```

首次运行：

```bash
cd /home/lillian/banshi
uv venv .venv                                   # 已创建则跳过
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python app.py
```

然后浏览器打开 http://127.0.0.1:5000 （建议用手机宽度或缩小窗口体验）。

首次启动会自动创建 `banshi.db`（SQLite 数据库）和 `.secret_key`
（会话密钥），数据完全存在本地，不会上传到任何地方。

再次运行只需：

```bash
.venv/bin/python app.py
```

停止服务：`Ctrl+C`。

## 已实现的 MVP 功能

- 账号系统（注册 / 登录 / 退出，密码哈希存储）
- 智能体管理：创建 / 编辑 / 删除多个角色，角色之间记忆完全隔离
- 对话页：短句风格聊天，输入含学习/家务/跑腿/运动/工作等各类现实任务关键词时触发【发现任务】弹窗
- 委托任务弹窗：任务名、简介、时长（25/45/60/自定义）、接取/暂不接取——任务是奇幻游戏世界风格
  的委托（讨伐、护送、跑腿、整理、侦查……），不管你现实中要做的是学习、打扫房间还是健身，都会被
  包装成一次游戏化的冒险，而不是原样照搬你说的内容
- 番茄计时页：倒计时，专注期间聊天输入被禁用，可中途放弃
- 任务交付：圆满完成 / 偶尔走神 / 中途放弃，角色按「说话风格 × 分心态度」生成对应台词
- 记录中心：数据看板（本月专注时长、完成率、打卡日历）+ 故事日志（时间线叙事）
- 响应式布局，移动端优先，桌面端自动加宽

## 关于本地大模型引擎

- 完全离线：所有请求只发往 `127.0.0.1:11434`（Ollama 默认地址），不连外网、不用 key。
- 模型质量提示：`llama3.2:3b` 是个较小的模型，中文短句整体可用，但偶尔会有用词生硬、
  极少数情况夹杂英文单词的情况——这是小模型的局限，不是 bug。如果想要更地道的中文
  角色扮演效果，可以换一个中文能力更强的本地模型，例如：
  ```bash
  ollama pull qwen2.5:7b-instruct
  ```
  然后设置环境变量再启动：
  ```bash
  OLLAMA_MODEL=qwen2.5:7b-instruct .venv/bin/python app.py
  ```
  （7B 模型约 4-5GB 下载，你的 16GB 显存跑起来完全没问题，回复速度可能比 3B 略慢一点。）
- 对话页顶部若出现"本地大模型未连接"提示，说明 `ollama serve` 没在跑，此时该角色会
  自动使用模板引擎回复，不影响正常使用。

## 之后想接入云端 LLM（Anthropic API 等）时

`llm_engine.py` 是唯一需要改的地方——保持 `generate_intro()` / `generate_reply()` /
`generate_outcome_line()` 的函数签名不变，把内部的 Ollama 调用换成 API 调用即可，
key 从环境变量读取，不需要改动 `app.py` 或模板。

## 目录结构

```
app.py          Flask 路由与业务逻辑
db.py           SQLite schema 与连接
dialogue.py     本地规则模板引擎 + 头像/任务库（两套引擎共用的兜底数据）
llm_engine.py   本地大模型引擎（调用 Ollama），失败时自动退回 dialogue.py
templates/      Jinja 页面模板
static/css/     样式
banshi.db       运行后自动生成的数据库（不提交）
.secret_key     运行后自动生成的会话密钥（不提交）
```
